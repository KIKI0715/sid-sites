  • — Context

    콘텐츠를 듣다가 누군가 이름을 부르면, 한쪽 이어버드를 빼고 대답한 뒤 다시 듣던 것으로 돌아간다. 카페 주문 대기, 편의점 계산, 사무실 업무 세 상황에서 공통으로 찾은 순간이고, 2차 테스트의 11명도 모두 말을 걸면 한쪽을 뺀다고 답했다.

    이 순간 사용자는 콘텐츠를 멈추기보다 소리를 줄이고 싶어 한다. 하지만 T17은 이어버드에서 볼륨을 조절할 수 없고 터치 인식도 믿기 어려워, 조작이 매핑되어 있어도 결국 폰을 꺼내게 된다.

  • — Prototype

    귀에서 바로 조작하는 시안 A(원형 본체에서 이어지는 짧은 기둥에 볼륨 슬라이드)와 케이스에 시소형 볼륨 버튼을 둔 시안 B 가운데 A를 골라, 모바일 화면에서 실제 크기 28mm로 조작하는 3D 웹 프로토타입을 만들었다.

    1차 테스트의 4명은 한 번 탭과 위아래 쓸기처럼 이미 아는 조작은 설명 없이 찾았다. 하지만 좌우 스와이프로 곡을 넘기는 조작은 3명이 찾지 못했고, 두 번 탭으로 직접 켜는 대화 모드는 1명만 쓰겠다고 했다.

  • — Mapping

    그래서 곡 넘기기를 두 번 탭(다음 곡)과 세 번 탭(이전 곡)으로 바꿨고, 2차 테스트에서 점수는 2점 만점에 0.00에서 0.82로 올랐다. 모든 조작은 좌우 구분 없이 같고, 착용 감지로 귀에 있을 때만 터치가 작동해 손에 쥔 버드가 잘못 눌리지 않는다.

    대화 모드는 사용자가 켜지 않아도 한쪽을 빼고 대화가 감지되면 자동으로 동작한다. 다만 11명 중 8명이 대화 중에는 볼륨 감소보다 일시정지를 원했고, 그 선택은 콘텐츠를 얼마나 놓치기 싫은지에 따라 갈렸다.

  • — Conclusion

    최종안은 세 가지 원칙으로 정리된다. 좌우 구분 없이 어느 쪽을 끼든 같은 조작, 다른 이어버드에서 이미 익힌 탭 횟수와 기둥 쓸기를 그대로 쓰는 아는 문법, 그리고 배워야 할 조작은 기기가 대신하는 자동 대화 모드다.

    다만 웹 프로토타입이라 실제 착용감, 주변 소음, 손가락 감각은 반영하지 못했고, 대화 감지는 구현하지 않아 혼잣말이나 주변 대화에 대한 오작동은 검증하지 못했다.

    리디자인의 세 가지 원칙

    Conclusion
    01
    좌우 구분 없이

    어느 쪽을 끼든 같은 조작. 한쪽만 껴도 기능이 사라지지 않는다.

    02
    아는 문법 그대로

    탭 횟수와 기둥 쓸기는 다른 이어버드에서 이미 익힌 조작이라 학습 비용이 적다.

    03
    배워야 할 조작은 기기가

    대화 모드는 사용자가 켜지 않아도 조건을 만족하면 자동으로 동작한다.

    향후 과제와 한계점

    Next
    향후 과제
    대화 중 처리 방식 심층 조사 · 커스텀

    볼륨 감소와 일시정지 가운데 무엇을 원하는지는 콘텐츠와 대화의 중요도에 따라 갈렸다. 사용자가 직접 고르는 커스텀 설정을 제공한다.

    더 직관적인 곡 이동 매핑

    이전 곡(세 번 탭)은 잘 찾지 못했다. 오른쪽 = 다음 곡, 왼쪽 = 이전 곡 의견도 있어, 한쪽만 끼는 맥락과 부딪히지 않는 매핑을 더 고민한다.

    한계점
    환경

    실제 착용감, 주변 소음, 손가락 감각을 반영하지 못했다.

    버전

    2차 테스트 도중 곡 넘기기가 스와이프에서 탭으로 바뀌어 응답 시점마다 시안이 다르다.

    구현

    대화 감지를 구현하지 않아 혼잣말 · 주변 대화에 대한 오작동을 검증하지 못했다.
